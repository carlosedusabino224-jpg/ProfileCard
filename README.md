# Card de Perfil

Projeto do dia 12 do meu desafio de projetos para praticar programação.

Nesse projeto fiz um card de perfil usando HTML e CSS, com minha foto, algumas informações, links e as tecnologias que estou estudando.

## Tecnologias

- HTML5
- CSS3

## O que foi usado

- Flexbox
- Gradiente
- Box Shadow
- Border Radius
- Hover
- Links externos
- Imagens
